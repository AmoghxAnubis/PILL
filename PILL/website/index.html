QUESTIONS

Before you install.

What is PILL? +

PILL is a Windows desktop overlay that surfaces media, telemetry, focus sessions and contextual information in a compact dynamic island.

What is PILL Control? +

PILL Control is the companion configuration application for managing PILL's widgets, behavior, appearance and system preferences.

How do I use the new dashboard? +

Hover or click the clock to expand. Use the tabs or arrow keys to move between Calendar, Weather, Media, Focus and System. Right-click for quick settings; Escape closes settings or collapses the island.

Is the 0.2 release finished? +

It is a development preview. Some features, including idle hiding, monitor placement and tray/startup completion, are still in progress. Update PILL and PILL Control together.

Which Windows versions are supported? +

The current PILL release is built specifically for Windows. Exact supported-version requirements will be documented with the public release.

Is PILL free? +

The current PILL release is distributed as a free and open-source Windows application through GitHub.
